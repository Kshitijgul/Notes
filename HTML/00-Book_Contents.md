## 🎯 Most Important Interview Topics

### HTML

- Semantic HTML
- Forms and validation
- `GET` vs `POST`
- `id` vs `class`
- Block vs inline elements
- `div` vs `span`
- `section` vs `article`
- `alt` attribute
- Accessibility basics
- SEO meta tags

### CSS

- Box model
- Specificity
- Cascade and inheritance
- Positioning
- `display: none` vs `visibility: hidden` vs `opacity: 0`
- Flexbox
- Grid
- Media queries
- Responsive design
- `em` vs `rem`
- `px` vs `%` vs `vw/vh`
- Transitions vs animations
- CSS variables
