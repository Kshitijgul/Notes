# ⚡ 17. Emmet (HTML/CSS Superpower)

Type

```html
ul>li*5
```

Press

```
Tab
```

↓

```html
<ul>
    <li></li>
    <li></li>
    <li></li>
    <li></li>
    <li></li>
</ul>
```

---

Type

```html
div.container>h1+p
```

↓

```html
<div class="container">
    <h1></h1>
    <p></p>
</div>
```

---

Type

```html
nav>ul>li*4>a
```

↓

```html
<nav>
    <ul>
        <li><a href=""></a></li>
        <li><a href=""></a></li>
        <li><a href=""></a></li>
        <li><a href=""></a></li>
    </ul>
</nav>
```

# ⭐ Top 20 Shortcuts to Master First

If you learn only these, you'll be productive in VS Code:

1. `Ctrl + Shift + P` → Command Palette
2. `Ctrl + P` → Open File
3. `Ctrl + Shift + F` → Search Project
4. `Ctrl + F` → Find
5. `Ctrl + H` → Replace
6. `Ctrl + /` → Comment
7. `Alt + ↑/↓` → Move Line
8. `Shift + Alt + ↓` → Duplicate Line
9. `Ctrl + D` → Select Next Match
10. `Ctrl + Shift + L` → Select All Matches
11. `F2` → Rename Symbol
12. `F12` → Go to Definition
13. `Alt + ←` → Go Back
14. `Ctrl + Space` → IntelliSense
15. `Shift + Alt + F` → Format Document
16. ``Ctrl + ` `` → Toggle Terminal
17. `Ctrl + B` → Toggle Sidebar
18. `Ctrl + Tab` → Switch Between Files
19. `Ctrl + Shift + E` → Explorer
20. `Ctrl + Shift + X` → Extensions

Mastering these shortcuts will make everyday development in React and other web technologies significantly faster.
